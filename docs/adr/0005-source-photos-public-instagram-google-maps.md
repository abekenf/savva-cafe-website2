# 0005. Фотографии — только из публичного Instagram и Google Maps, без стока

## Контекст

Сайту нужны фотографии кофейни для hero, меню и галереи. Пользователь ограничил
источник: «только то, что есть в открытом доступе». Доступные кадры из
Instagram — 640×640, для полноэкранного hero на ретине этого мало.

## Решение

Кадры берутся из публичного Instagram `@savva_cafe` (640×640) и с карточки
Google Maps. Каждый файл фиксируется в `ASSETS.md` строкой «файл — источник —
дата». Hero строится на самом крупном доступном интерьерном кадре с мягким
затемняющим градиентом, скрывающим мягкость исходника. Позиции меню без
собственного кадра получают фирменную плитку sage с монограммой, а не чужую
картинку.

## Почему

Стоковые фотографии для недостающих кадров меню отвергнуты: сайт должен
показывать само заведение (R28 — «фотографии должны основываться на
материалах Instagram и Google Maps»), чужой сток нарушил бы это прямо.
Покупка или заказ профессиональной съёмки отвергнуты на этом этапе —
не входит в доступ пользователя «только открытые источники»; это оставлено
как открытый пункт для владельца, а не решено явочным порядком.

## Последствия

Качество hero-изображения ограничено исходником 640×640 и держится только
градиентом — на больших экранах мягкость видна. Замена на снимки в высоком
разрешении — открытая задача владельца (`ASSETS.md`, раздел «Открытые
места»), а не техническая правка: она меняет сам файл, не код.
