# 0004. Карта Google — iframe без API-ключа, подгружается по клику

## Контекст

Встраивание карты в блок Visit Us требует либо `<iframe>` с `output=embed`
(без ключа), либо Maps Embed API с API-ключом. Нужна была «большая карта» без
торможения загрузки первого экрана.

## Решение

Карта встраивается через `<iframe src="...output=embed">` — ключ API не
нужен. До клика на её месте — статичная превью-плитка (картинка карты,
приглушённая на 40%) с кнопкой «Show map»; сам `<iframe>` с `loading="lazy"`
подставляется только после клика.

## Почему

Maps Embed API с ключом отвергнут: он требует завести ключ, привязать его к
биллинг-аккаунту владельца и хранить его в проекте — лишняя внешняя
зависимость и точка отказа ради виджета, который и без ключа доступен через
`output=embed`. Немедленная (не по клику) загрузка iframe отвергнута отдельно:
Google Maps тянет сторонние скрипты и тормозит первый экран, что противоречит
требованию быстрой загрузки на 4G.

## Последствия

Ссылка на карту жёстко привязана к канонической ссылке карточки Google,
присланной пользователем (`cid=10124017331193347009`) — смена заведения или
переезд потребует замены этой ссылки и в Visit Us, и в футере (это две разные
строки, не общий «соцсети»-блок). Если Google изменит контракт
`output=embed`, встраивание сломается без предупреждения — платного API с
поддержкой SLA здесь нет.
