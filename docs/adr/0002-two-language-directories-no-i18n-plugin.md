# 0002. Два языка — две директории без i18n-плагина, RTL логическими свойствами

## Контекст

Пользователь потребовал двуязычный сайт (английский + арабский) с полноценным
RTL-режимом (справа налево) — это новое требование сверх брифа (G01). Языков
ровно два, и такими они останутся.

## Решение

Каждый язык — отдельная директория шаблонов (`src/en/`, `src/ar/`), с
собственным файлом данных (`en.json` / `ar.json`), задающим `lang`, `dir` и
словарь `t`. Обе директории подключают одни и те же девять секций из
`_includes/sections/`. RTL делается логическими CSS-свойствами Tailwind
(`ps-`, `pe-`, `ms-`, `me-`, `start-`, `end-`), а не зеркальными
переопределениями стилей.

## Почему

Плагин i18n для Eleventy отвергнут: он оправдан при росте числа языков или
динамической маршрутизации, а здесь их ровно два и `hreflang`-ссылки пишутся
явно руками — плагин добавил бы движущийся узел без выгоды. Зеркальные
CSS-переопределения для RTL отвергнуты: пришлось бы держать каждое правило
отступов и выравнивания в двух версиях, что расходится вдвое на каждой правке
стиля.

## Последствия

Третий язык — не «добавить строку в конфиг», а завести третью директорию
шаблонов и данных и продублировать структуру — цена решения проявляется только
при росте числа языков. Переключатель языка — обычная ссылка без сохранения
позиции на странице (переключение всегда ведёт на верх), это принятое
ограничение, а не недосмотр.
