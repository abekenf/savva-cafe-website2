# 0001. Стек — Eleventy 3 + Nunjucks + Tailwind CSS 4 + ванильный ES6

## Контекст

Бриф разрешает два варианта стека: «HTML5 + CSS3 + Tailwind + ES6» или
«React + Next.js + Tailwind». Страница одна, неинтерактивная, но нужна на двух
языках, и есть жёсткие требования — минимальный JavaScript, Lighthouse
Performance > 95.

## Решение

Сайт собирается генератором статики Eleventy 3 с шаблонами Nunjucks и Tailwind
CSS 4. На выходе — чистые HTML5, CSS3 и ES6, без рантайма фреймворка.

## Почему

Next.js отвергнут: гидратация принесла бы ~90 КБ JavaScript ради лайтбокса,
которому хватает 2 КБ, — это прямо против требований «минимальный JavaScript»
и Lighthouse > 95. Голый HTML без шаблонизатора тоже отвергнут: языков два,
и без шаблонизации разметка дублировалась бы вручную и расходилась бы уже на
второй правке. Eleventy выбран как сборка, а не рантайм — она не добавляет
ничего поверх HTML5/CSS3/ES6 из брифа.

## Последствия

Любая будущая интерактивность (корзина, бронирование, персонализация) потребует
либо ручного JS поверх статики, либо пересмотра этого решения и миграции на
фреймворк — с нуля переписывать шаблоны и сборку. Разработчик, продолжающий
проект, должен знать Eleventy/Nunjucks, а не только React.
