## Что должно заработать

Страница оживает: блоки проявляются при скролле, шапка становится матовой, фон hero
отстаёт при прокрутке, фотография открывается крупно, кнопка возвращает наверх,
мобильное меню открывается и закрывается, карта подгружается по клику, а под часами
работы появляется «сейчас открыто». Всё это — один файл не тяжелее 8 КБ без зависимостей.

## Что именно построить

Семь независимых функций, каждая ищет свои `data-`атрибуты и молча выходит, если их нет.

1. **reveal** — `IntersectionObserver`, порог 0.15, добавляет класс на элементы
   с `data-reveal`; `data-reveal-delay` даёт stagger 60ms. Наблюдение снимается
   после срабатывания.
2. **nav** — класс на шапке после 40px (`IntersectionObserver` на сентинел, не `scroll`);
   `aria-current` на секции в вьюпорте; бургер по `data-nav-toggle` — блокировка
   скролла `body`, ловушка фокуса, Esc, закрытие по клику на пункт, `aria-expanded`.
3. **parallax** — `data-parallax`, `translate3d(0, scrollY*0.12, 0)` в `requestAnimationFrame`.
   Ровно 12%, ничего кроме `transform` не меняется.
4. **lightbox** — `<dialog>`, создаётся один раз при первом клике. Группа берётся из
   `data-lightbox-group`. Стрелки ←/→, Esc, свайп на тач, клик по фону,
   `aria-modal`, подпись из `alt`, ловушка фокуса, возврат фокуса на плитку при закрытии.
5. **toTop** — кнопка `data-to-top`, появляется после первого экрана,
   `scrollTo({behavior:'smooth'})`, второй разрешённый glassmorphism.
6. **map** — клик по `data-map` заменяет превью на `<iframe>` из `data-map-src`,
   `loading="lazy"`, `title` из словаря, `allowfullscreen` не нужен.
7. **hours** — `data-hours`: вычисляет по времени Эр-Рияда (UTC+3), открыто ли сейчас,
   и пишет «Open now · closes 2 AM» или «Opens at 6:30». Часы берёт из `data-`атрибута,
   который положила секция, а не из своего копирования расписания.

**`prefers-reduced-motion: reduce`** выключает 1 и 3 полностью: содержимое показано
сразу, слой неподвижен. 4, 6 и 7 работают всегда.
**`@media (hover: none)`** отключает hover-состояния из спецификации §12.

## Критерии приёмки

- [ ] `app.js` не больше 8 КБ без сжатия, ни одной зависимости
- [ ] С выключенным JavaScript видны все девять секций, весь текст, адрес, телефон и часы
- [ ] При `prefers-reduced-motion` блоки видны сразу, параллакса нет
- [ ] Лайтбокс открывается, листается стрелками, закрывается Esc, возвращает фокус
- [ ] Мобильное меню запирает фокус и не даёт прокручивать страницу под собой
- [ ] Карта появляется только после клика
- [ ] «Сейчас открыто» согласуется с таблицей часов в пятницу и в остальные дни
- [ ] Ни одной ошибки в консоли на обеих языковых версиях
