## Что должно заработать

В репозитории лежит набор настоящих фотографий Savva — интерьер, напитки, десерты,
общие планы, — каждая с записанным происхождением, и конвейер изображений из таска 01
собирает из них адаптивные наборы. Ни одного стокового кадра, ни одной чужой кофейни.

## Разделы спецификации

Решения §5 и §7, история 24, «Открытые места».

## Что именно построить

- Собрать кадры из публичного Instagram `@savva_cafe` и из фотографий карточки
  Google Maps (`https://www.google.com/maps/place/سافا+savva/@24.4926931,39.5823565,17z`).
  Instagram отдаёт сетку постов по 640×640 без авторизации; Google Maps — крупнее.
  Приоритет по назначению:
  - **hero** — самый крупный доступный интерьерный кадр, желательно горизонтальный;
  - **gallery** — минимум 9, максимум 15: интерьер, столики, барная стойка, улица,
    подача, детали;
  - **menu** — по одному кадру на шесть позиций, насколько получится;
  - **instagram** — девять последних публикаций профиля;
  - **logo** — аватар профиля в максимальном доступном размере.
- Раскладка: `src/assets/images/{hero,gallery,menu,instagram,brand}/`,
  имена — латиница, kebab-case, по содержимому (`interior-window-seat.jpg`), не по id поста.
- `ASSETS.md` в корне: таблица «файл — источник (URL) — дата съёма — что на кадре».
  Строка на каждый файл, без исключений.
- Для позиций меню, которым не нашлось своего кадра, **не подставлять чужое**:
  записать их список в конец `ASSETS.md` под заголовком «Нужен кадр» — таск 04
  поставит там фирменную плитку.
- Проверить, что шорткод `image` из таска 01 собирает из этих файлов AVIF, WebP и JPEG
  и что ни один исходник не тяжелее 1.5 МБ.

## Критерии приёмки

- [ ] ≥ 20 файлов в `src/assets/images/`, все — материалы Savva
- [ ] У каждого файла строка происхождения в `ASSETS.md` с URL и датой
- [ ] Есть хотя бы один горизонтальный интерьерный кадр для hero
- [ ] В галерее ≥ 9 кадров, среди них есть интерьер
- [ ] Позиции меню без кадра перечислены в `ASSETS.md` под «Нужен кадр»
- [ ] Тестовая сборка порождает для каждого кадра AVIF/WebP/JPEG в четырёх ширинах
